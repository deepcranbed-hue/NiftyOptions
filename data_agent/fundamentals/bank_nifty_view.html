The regime button switches which rule dominates, using our validated per-regime P/B rank-ICs: in Improving cheap re-rates (IC −0.52) so cheap+improving = buy; in Deteriorating cheap is punished (IC +0.12) so cheap = value-trap avoid; in Normalized (today) the factor edge is ~0, so momentum/quality lead and cheapness is inert.

Hard caveats: this is a Product-B thesis, not a tradeable signal — n = 3 years per regime (one instance of each cycle), bank returns are gap-locked, the rule is not operational without a live regime detector (an RBI system-GNPA series).
